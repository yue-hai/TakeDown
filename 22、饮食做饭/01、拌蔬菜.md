# 二、蔬菜

## 1、叶菜与软性蔬菜类

> 规则：  均需焯水，捞出后必须用力挤干水分。

| 食材        | 焯水时间       | 处理细节                 |
| :-------- | :--------- | :------------------- |
| 菠菜 / 茼蒿   | 30 \~ 40 秒 | 必须煮（去除草酸），水里加少许盐保持翠绿 |
| 绿豆芽 / 黄豆芽 | 60 秒       | 捞出后必须立刻过冷水，极致爽脆      |
| 紫洋葱       | 0 秒 (生食)   | 切极细丝，放约 15g 提香即可     |

## 2、脆感茎花类

> 规则：  焯水后必须立刻投入冰水/凉白开浸泡 30 秒，利用热胀冷缩锁定脆感

| 食材  | 焯水时间        | 处理细节                  |
| :-- | :---------- | :-------------------- |
| 西兰花 | 1.5 \~ 2 分钟 | 切小朵，水里滴一点油            |
| 芦笋  | 1.5 分钟      | 削去根部老皮后切段             |
| 秋葵  | 1.5 分钟      | **必须整根下锅煮**，煮熟过凉水后再切段 |
| 胡萝卜 | 30 秒 (或生吃)  | 切极细丝，做调色用             |

## 3、多孔吸汁类

> 规则：  非常适合搭配重口味（配方3），需控干水分

| 食材        | 焯水时间      | 处理细节                 |
| :-------- | :-------- | :------------------- |
| 金针菇       | 3 分钟以上    | 必须彻底煮熟，否则易肠胃中毒       |
| 黑木耳       | 3 分钟      | 冷水提前泡发 30 分钟，彻底煮熟    |
| 菇类 (杏鲍菇等) | 3 分钟      | 煮熟后手撕成丝，口感似鸡肉        |
| 海带丝 / 裙带菜 | 3 \~ 5 分钟 | 原本带有微咸味，拌汁时可少倒一些底层酱汁 |

## 4、免煮生食类

| 食材    | 焯水时间 | 处理细节                       |
| :---- | :--- | :------------------------- |
| 黄瓜    | 0 秒  | 必须用刀拍碎。加 3g 盐腌制10分钟脱水后再洗净拌 |
| 纯魔芋丝结 | 2 分钟 | 煮一下去除包装水里的碱味，控干水           |
| 小番茄   | 0 秒  | 对半切开，汁水能融入调料，增鲜增甜          |


# 三、水果

## 1、黄柠檬 / 青柠

- 用途：提供高级强酸（柠檬酸）与果皮精油香气
- 存放：冷藏放入保鲜袋，可存放 30 天。切开用了一半的，切面封保鲜膜放冷藏
- 提取：必须**现挤现用**，提前放入酱油过夜会发苦发黑

## 2、百香果

- 用途：提供复合热带甜酸香（自带少许果糖）
- 存放：常温通风处放置。可存放 10\~15 天
- 判定：表皮变皱变干是果糖熟化的标志（最香甜），捏上去烂成水才需要扔掉

# 四、蛋白质

> 减脂不能只吃蔬菜，必须加入以下蛋白质提供饱腹感

## 1、水产与肉类

- 虾仁：焯水 1\~2 分钟至变红卷曲。极度搭配【泰式青柠汁】
- 鸡胸肉：煮熟后顺着纹理**手撕成丝**，挂汁能力满分

## 2、豆制品类

- 千张（豆腐皮） ：切丝，焯水 2 分钟（去生豆腥味），极度搭配【灵魂椒麻汁】
- 内脂豆腐：无需加水，直接盖保鲜膜微波炉高火转 3 分钟。搭配【经典蒜香果醋汁】
- 腐竹：折断后用温水泡软，再焯水 2 分钟。

## 3、蛋类

- 水煮蛋：切成块状拌入蔬菜，蛋黄溶于酱汁后会提供类似“沙拉酱”的醇厚感
- 无油炒蛋片：不粘锅干煎，切片拌入菌菇中，极度鲜美

# 五、经典大拌菜拼配公式

> 规则：  每次拌菜，从上面选 【1种吸汁食材 + 1种硬脆食材 + 1种软蛋白质 + 少量视觉点缀】

## 1、经典中式大拌菜 (重口味、嘎嘣脆)

- 材料：黑木耳 + 拍黄瓜 + 腐竹段 + 紫洋葱丝
- 对应调料：【1 经典蒜香果醋汁】 或 【3 灵魂椒麻汁】

## 2、泰式低卡海鲜碗 (极度清新、夏日首选)

- 材料：魔芋丝结 + 鲜虾仁/撕鸡胸肉 + 小番茄块 + 西兰花小朵
- 对应调料：【2 泰式青柠原鲜汁】

## 3、假装吃凉面 (欺骗神经的顶级饱腹)

- 材料：海带丝 + 绿豆芽 + 千张(豆腐皮)丝 + 胡萝卜丝
- 对应调料：【3 灵魂椒麻汁】（完全当麻辣面条吃）

## 4、高能鲜菇补铁盆 (软糯鲜香)

- 材料：菠菜段 + 杏鲍菇丝 + 金针菇 + 煮鸡蛋块
- 对应调料：【1 经典蒜香果醋汁】
